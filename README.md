## 哪些人不必买 Vultr，或者不必买贵的档

**纯静态博客、作品集、文档站。** 最低档足够。Hugo、Astro 生成的静态文件，512MB 内存跑 Caddy 绰绰有余，压力主要来自带宽而不是 CPU。

**需要跑数据库或多容器。** 1GB 是起步线，而且建议把数据库放到独立的块存储上，实例盘只放系统和无状态文件。实例随时可能被销毁重建，数据放在实例盘上等于把单点故障留在自己手里。

**大文件下载站、图床。** 不要指望实例带宽。静态资源放对象存储，前面挂 CDN，实例只做源站和动态逻辑。用最低档机器扛下载流量，流量超额的费用会比机器本身贵。

**长时间 100% CPU 的任务。** 视频转码、压力测试、密集爬虫，这类负载在共享 CPU 实例上会被邻居影响，也不保证持续性能。要跑这类任务，要么上 Optimized Cloud Compute 的独享型，要么换独立服务器。

**需要强 SLA 或合规审计的业务。** 支付、核心交易系统、需要 ISO 27001 / SOC 2 的场景，这个价位段本来就不该考虑。

## 下单前要确认的几件事

**共享 CPU 会超分。** Cloud Compute 的 vCPU 不是独占核心，平台会把物理核心分配给多个实例。短时间能突发到满核，持续满载不保证性能。这是价格便宜的原因，也是它不适合重负载的原因。

**流量超额另计费。** 每档包含一定出站流量，超出部分按地区单价收费。开账单告警，定期看出站用量，比事后核对账单省事。

**备份、快照、额外 IPv4 都是付费项。** 基础套餐不含自动备份。重要数据自己用 `restic` 或 `rsync` 推到异地，比开平台备份便宜。

**服务条款对用途有限制。** 挖矿、批量发信、公开代理、高密度爬虫这类用途在多数便宜 VPS 的 AUP 里都被禁止，触发后账号可能被停。买之前扫一眼条款，比被封了再申诉省时间。

**创建页显示“限量”不是故障。** 某些机房某些档位会临时缺货，换同洲的另一个机房即可，不必等。

**不退款。** Vultr 官方的退款政策写明服务费用不退，账户信用也不可退现。这是它和提供“7 天无理由”的商家的重要差别，下单前想清楚。
